# Variables de precios

Modificá únicamente el número para definir el porcentaje de ganancia aplicado al precio de lista de cada unidad.

Por ejemplo, `5` agrega un 5%: un precio de lista de USD 100 se muestra como USD 105.

Elige si el widget muestra o no el precio de venta, S es sí mostrar, N es no mostrar.

Elige si el widget muestra o no las unidades disponibles para cada modelo. ejemplo "(3 uds) de Iphone 15 PRO MAX 256 black..."

[ganancia]: 5
[mostrar_precio]: S
[mostrar_uds_dispo]: N
